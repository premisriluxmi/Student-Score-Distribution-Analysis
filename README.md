# Student Score Distribution Analysis

## About the Project
This project explores the distribution of student scores using Python, Pandas, and Matplotlib. A histogram is created to understand how numerical scores are distributed.

## Objective
To understand the distribution of numerical data by creating a histogram and examining concentration, spread, and possible skewness.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Dataset
The dataset contains 30 sample student records with student IDs and numerical scores. It is created for this learning project.

## Steps Performed
1. Imported Pandas and Matplotlib.
2. Created a student score dataset.
3. Explored the data and calculated descriptive statistics.
4. Created a histogram using `plt.hist()`.
5. Examined score concentration, spread, and possible skewness.
6. Saved the dataset as a CSV file and the histogram as a PNG image.

## Key Observations
- Scores vary across multiple intervals.
- The minimum and maximum scores show the overall spread.
- The histogram helps identify where scores are concentrated.
- The skewness value helps describe the shape of the distribution.

## Files
- `Student_Score_Distribution_Analysis.ipynb` — Notebook containing the analysis.
- `student_scores.csv` — Dataset.
- `student_score_histogram.png` — Histogram visualization.
- `README.md` — Project documentation.

## Conclusion
This project demonstrates how a histogram can help analyze numerical data and understand its distribution.
